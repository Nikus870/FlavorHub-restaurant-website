# FlavorHub – Project Report

## Objective
To develop a responsive restaurant website that provides an online presence for FlavorHub and demonstrates menu browsing, table reservations, online ordering, reviews and contact functionality.

## Technologies
HTML5, CSS3 and JavaScript. JavaScript arrays/objects are used for application data and localStorage is used for browser-side persistence.

## Features
Responsive homepage, categorized menu, dietary filters, search, table reservation, shopping cart, checkout, order confirmation, restaurant information, chef profiles, gallery, reviews, contact form with map, and simulated authentication.

## Learning Outcomes
Learned semantic HTML structure, responsive CSS layouts, JavaScript DOM manipulation, event handling, arrays/objects, forms, localStorage and frontend project organisation.

## Challenges
Managing multiple pages with shared navigation, keeping cart/reservation data persistent, making the layout responsive, and connecting JavaScript interactions with HTML elements were the main challenges.

## Conclusion
FlavorHub demonstrates a complete frontend restaurant experience suitable for the WD-RES-001 internship requirements.
