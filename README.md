# FlavorHub – Restaurant Website

Task ID: WD-RES-001  
Domain: Restaurant Website  
Company: Data Alcott Systems  
Technology: HTML5, CSS3, JavaScript

## Features
- Responsive restaurant homepage
- Dynamic menu with category, dietary filters and search
- Table reservation system using localStorage
- Online food ordering, cart and checkout
- About, chefs and restaurant history
- Gallery
- Customer reviews and ratings
- Contact form and embedded map
- Login/Register simulation using localStorage
- Responsive mobile navigation
- Promotional coupon `FLAVOR15`

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Deployment
This project can be deployed on GitHub Pages, Netlify or Vercel.
